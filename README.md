## 📌 The business problem

Starlent wanted Open edX to **look and feel like their own product**, for both learners and course creators, and to **sell
courses online** instead of only enrolling learners by hand.

## ✅ My contribution

| Area | What was built | Value for the client |
|---|---|---|
| 🎨 **Complete brand theme: learner site** | Dashboard, course discovery and filters, instructor pages, certificates, login, profile and account, all in Starlent's colours and fonts | A platform that is unmistakably theirs |
| 🛠️ **Complete brand theme: Studio** | Course-creation screens and components restyled to match | Course creators work inside the same brand |
| 🌍 **Right-to-left support** | Layouts that work for RTL languages | Ready for more regions |
| 🛒 **E-commerce** | Courses and subscription plans sold online; admins choose which courses each plan unlocks; learners buy and get instant access | A recurring revenue model on the platform |

## 📈 Business impact

- **Brand ownership:** learners and instructors never see a "generic" Open edX.
- **Revenue:** online sales and subscriptions straight from the platform.
- **Maintainable:** delivered as a Tutor theme and brand package, so it stays upgradeable.

**Tech:** Open edX themes (LMS and Studio), Paragon brand package, SCSS, React micro-frontends, Tutor.
